# 未成年人智能陪伴守护

描述未成年人智能陪伴中的授权、风险信号和真人支持边界。

## 领域资料

- `contracts/context.schema.json` 约定基础资料格式，`fixtures/context.json` 提供不含真实个人信息的示例。
- `contracts/policy.schema.json` 约定守护服务策略格式，`fixtures/policy.json` 给出对应的脱敏示例。
- 代码模块负责读取和校验这些资料，后续业务服务可以沿用其中的领域标识、键名与版本约定。

当前资料记录了以下业务事实：

- 调查中有未成年人表现出只想与智能助手交流的倾向
- 智能陪伴可能形成情感依赖和现实关系回避
- 相关讨论强调智能工具不能替代真实关怀
- 深夜连续倾诉不必然等于心理危机，使用时长不能单独作为风险标签依据

策略资料把上述事实落成可校验的边界：

- **最少收集的五类数据**：使用时段窗口、风险信号、主动求助、监护与学校授权、真人关怀结果；各自带明确的摘要保存期限与原始内容删除期限。
- **三条处置路径**：普通情绪表达（机器共情、不贴标签）、持续孤立倾向（真人温和接触、禁止仅凭时长判定）、紧急伤害风险（立即转真人应急处置）。
- **转人告知**：转给真人前必须在对话中提前告知孩子；紧急情形可先处置、事后说明。
- **教师视角**：只呈现支持行动与跟进状态，不呈现风险评分、诊断性措辞或原始对话。
- **规则版本**：每条处置绑定规则版本号，规则更新不回溯改写旧处置。
- **五类可追溯事件**：监护关系变化、同意撤回、校内外账号归并、误报申诉、夜间交班。
- **年龄段与脱敏资料**：年龄段（6–9、10–12、13–15、16–17）给出差异化边界；脱敏事件资料仅用于校准边界与信号阈值，禁止回链到具体学生。

## 本地校验

运行项目自带测试可确认示例资料能够读取，领域标识、版本、三条路径、留存期限、可追溯事件和各项守护开关完整一致：

```
python -m unittest discover -s tests
```

示例中的编号均为虚构值，不包含账号、凭据或真实主体信息。
