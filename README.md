# 未成年人智能陪伴守护

描述未成年人智能陪伴中的授权、风险信号、留存边界和真人支持边界。

## 领域资料

`contracts/context.schema.json` 约定基础资料格式，`fixtures/context.json` 提供不含真实个人信息的示例。代码模块只负责读取和校验这些资料，后续业务服务可以沿用其中的领域标识与版本约定。

当前资料记录了以下业务事实与约定：

- 调查中有未成年人表现出只想与智能助手交流的倾向，智能陪伴可能形成情感依赖和现实关系回避
- 深夜连续倾诉只是使用情境，**不单独构成心理危机**；学校侧不得仅凭使用时长为学生贴标签
- **最小必要收集**：只处理使用时段、风险信号、主动求助、监护与学校授权、真人关怀结果
- 三类信号走不同处置路径：
  - `ordinary-emotion` 普通情绪表达——对话内支持，不升级、不贴标签
  - `persistent-isolation` 持续孤立倾向——持续关注，告知本人后衔接真人关怀
  - `urgent-harm` 紧急伤害风险——立即转真人应急响应
- 原始对话内容到期删除；必要摘要须有明确保存期限；**规则更新不溯及改写旧处置**
- 年龄段资料（`age-bands`）与脱敏事件资料（`de-identified-events`）用于建立判定边界
- 监护关系变化、撤回同意、校内外账号归并、误报申诉、夜间交班均为须可追溯的事件
- 转真人前必须提前告知孩子；教师界面只呈现支持行动，不呈现未经核实的诊断

## 版本约定

资料版本为整数且单调递增。当前为 `version: 2`：v1 仅含领域事实，v2 增加收集范围、分流路径、留存规则、边界资料、可追溯事件与保障措施。后续规则更新只提升版本号并作用于其后的处置，不回头改写旧版本下已完成的处置。

## 本地校验

运行项目自带测试可确认示例资料能够读取，且领域标识、版本、收集范围、三类分流路径、留存规则与关键保障措施完整：

```
python -m unittest discover -s tests
```

示例中的编号均为虚构值，不包含账号、凭据或真实主体信息。
